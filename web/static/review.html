성과 지표
총 수익률
(final − initial) / initial × 100
연간 환산 수익률
(final/initial)^(1/years) − 1  │  years = n_days/252
Sharpe Ratio
(E[r] − rf) / σ × √252  │  rf = 3%/year
Sortino Ratio
annualized_return / downside_std × 100
Calmar Ratio
annualized_return / |MDD|
MDD
min((equity − cummax(equity)) / cummax(equity))
연간 변동성
std(daily_returns) × √252 × 100
Equity Curve
value[t] = cash[t] + position[t] × close[t]
Buy&Hold
shares = initial / close[0]  │  value[t] = shares × close[t]
기술적 지표
MACD (12,26,9)
MACD = EMA(12) − EMA(26)  │  Signal = EMA(9) of MACD
Golden cross (MACD↑Signal) → BUY  │  Dead cross → SELL
KDJ (9,3,3) + RSI(14)
K = Stoch(9,3)  │  D = EMA(3,K)  │  J = 3K − 2D
K<20 & RSI<30 → BUY  │  K>80 & RSI>70 → SELL
ZMR (20)
Z = (price − MA20) / std20
Z < −1.5 → BUY  │  Z > 1.5 → SELL
Bollinger (20, 2σ)
Upper = MA20 + 2σ  │  Lower = MA20 − 2σ  │  %B = (price−Lower)/(Upper−Lower)×100
price ≤ Lower → BUY  │  price ≥ Upper → SELL
포트폴리오 실행 규칙
BUY 수량
qty = int(cash × 0.5 / price) — 가용 현금의 50% 사용
SELL
전량 매도: cash += position × price  │  position = 0
